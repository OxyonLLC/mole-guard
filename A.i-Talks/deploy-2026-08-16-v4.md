## 5. Before the first real Tuesday — the three unexercised checks

The send is tested to destruction in unit tests and has never run against a
chain. Once an epoch is activated, do these **in this order**, with a real but
tiny epoch (`--pool=10` is fine):

1. **One participant, `--apply`.** Then verify on Solscan that **exactly one**
   transfer exists. Not "a transfer" — exactly one.
2. **Kill the process between submit and confirm**, restart, and run again. It
   must say *"already landed — recorded, not resent"*. If it sends a second
   transaction, stop and report.
3. **Re-run a completed batch.** Every chunk must be skipped.

Until all three pass, treat the payout path as unproven regardless of what the
test suite says.
