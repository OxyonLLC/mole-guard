Connect the wallet holding this key. With a Ledger, attach it and open the Solana app first.

    

      This is probably a derivation path difference, not the wrong device.
      One Ledger shows different addresses in different apps, because they derive Solana differently:
      
Ledger Live   m/44'/501'/0'      →  usb://ledger?key=0
Phantom       m/44'/501'/0'/0'   →  usb://ledger?key=0/0

      Both are real keys from the same seed. Decide which one is the signer, record the path
      alongside the address, and sign with a tool pointed at that path — the signer set
      is immutable once created, so the address you commit is the address you are stuck with.
