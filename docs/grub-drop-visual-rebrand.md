# Grub Drop visual rebrand (2026-07-19)

Full-detail spec from the user: replace the generic fruit-colored-square
art with a WinLEW/mole-themed underground identity — six named
collectibles with rarity tiers, a themed board, per-type match effects, a
recurring mole mascot, and a new thumbnail — while preserving gameplay,
mechanics, balance, and board dimensions exactly.

**Tool constraint, stated up front to the user before starting**: no
image-generation tool is available — this is hand-authored canvas-drawing
code and hand-authored SVG, not illustrated/painted sprite art. It's a
real, substantial visual upgrade over flat colored squares, but it does
not literally match hand-painted Supercell/Nintendo-tier illustration.

## What changed

**`src/public/mole-hub/js/games/grub-drop.js`**:
- `GRUBS` (4 generic colors) → `COLLECTIBLES` (6 named/tiered items:
  Earthworm/Fat Grub/Mushroom = common, Crystal/WinLEW Coin = rare, Golden
  Grub = epic), each with its own hand-drawn canvas shape (gradients, soft
  shadows/glow on rares+epic, distinct silhouettes — not just recolored
  squares).
- **Board mechanics preserved, spawn mechanic tuned via simulated
  playtesting (2026-07-19)**: matching is still same-type flood-fill, same
  scoring formula, same session-end condition, same 8×11 board. The first
  pass spawned all 6 types via independent per-cell weighted random
  (`SPAWN_WEIGHTS = [30,30,22,9,6,3]`). Rather than guess whether that
  balance was fair, it was playtested by simulation — extracted the exact
  matching/settling algorithm into a standalone script and ran 2000
  simulated sessions. Result: a real, concrete problem, not a vibe —
  Golden Grub (epic) only ever got successfully matched **30-38%** of the
  time, WinLEW Coin (rare) **51-62%**. With so few cells of a rare type
  scattered independently across 88 cells, most never happened to land
  next to a matching neighbor — players would see the exciting epic pull
  and then usually never get to pop it. Tried boosting the weights
  further (simulated 4 more configurations); diminishing returns — even
  doubling epic's share only reached 47%, while diluting the "rare" feel
  and dragging commons down from ~87% to ~80%.

  **Fixed with the mechanic match-3 games actually use for this**: rares/
  epic no longer spawn independently — `emptyGrid()` stamps a fixed count
  of GUARANTEED ADJACENT PAIRS onto the board first (`CRYSTAL_PAIR_COUNT
  = 3`, `COIN_PAIR_COUNT = 2`, `GOLDEN_PAIR_COUNT = 1`), then fills every
  remaining cell with weighted commons (`COMMON_WEIGHTS = [40, 40, 30]`
  for worm/grub/mushroom). Every rare/epic pull now starts already
  matchable. Re-simulated: clear rates for every type landed in the
  **89-94%** range (commons included), average pops/session barely moved
  (~21 → ~22). Rarity now comes from how often a pair appears on the
  board, not from starving each pull of a partner to match with. Verified
  the real implementation (not just the simulation) produces visibly
  adjacent pairs via a live screenshot before considering this done.
- New board texture (`buildBoardTexture()`): dirt gradient, speckled
  rocks/moss, faint root strands, built once to an offscreen canvas (not
  regenerated every frame, which would flicker) — replaces the flat
  `rgba(0,0,0,.28)` panel.
- New match particle system (`spawnMatchParticles`/`drawParticles`):
  bursts tinted to the popped collectible's palette, sparkle-shaped for
  Crystal/Golden Grub, bigger bursts for rare/epic pops. **Scoped down
  from the spec's fully bespoke per-type effect list** (dirt burst /
  dust puff / spores / light rays / coin spin / confetti as six distinct
  systems) to one shared, tinted/shaped system — a real effect, not the
  full spec.
- New mole mascot (`drawMoleMascot()`), fixed in the board's top-left
  header space: idle / happy (any pop) / excited (combo x3+, or any
  rare/epic pull) / celebrate (full board clear, with a bounce + sparkle
  burst) expressions, driven by `moleExpression`/`setMoleExpression()`,
  called from `tapAt()` and `endSession()`.

**`src/public/mole-hub/assets/grubdrop-card.svg` + `.png`** (2026-07-19,
follow-up ask): new thumbnail — a mole reaching toward a partially-visible
game board showing Fat Grub/Mushroom/Earthworm/Crystal/WinLEW Coin/Golden
Grub, underground cave gradient background, root strands, sparkle
accents, "Grub Drop — A WinLEW Underground Original" wordmark. The PNG
(what the hub catalog card actually renders — `catalogGames`'s `thumb`
field points at the `.png`, not the `.svg`) was regenerated by rendering
the new SVG in headless Chromium and screenshotting at the original's
exact 1672×941 resolution, since no SVG-to-PNG conversion tool
(rsvg-convert/imagemagick/sharp) is installed in this environment.

## Verification

- Rendered live via Playwright (both a 700×1200 desktop-ish viewport and
  a 390×844 mobile viewport) and visually inspected screenshots — distinct
  readable shapes per collectible, working glow on rares/epic, board
  texture visible, mole mascot present, no layout regressions on either
  viewport.
- All 5 hub games re-launched on both mobile (390×844) and desktop
  (1440×900) viewports after the change: zero page errors.
- New thumbnail verified rendering correctly inside the actual hub
  catalog card (16:9 crop via `.catalog-thumb`), not just standalone.
- `node --test test/nav/site-nav.e2e.test.mjs` — full pass, no
  regressions to the rest of the site.

## Explicitly not done (scope was too large for one pass — flagged, not silently skipped)

- Full UI chrome redesign (sidebar/buttons/stat panels/reward-overlay
  restyled to the underground theme) — the site's existing palette
  already leans warm-brown/gold, so this should be a lighter lift than
  the collectibles were, but it wasn't touched this pass.
- Bespoke per-collectible match effects (six distinct systems per the
  spec) — currently one shared, tinted/shaped system instead.
- Mole mascot only has 4 broad states in the game canvas corner; the spec
  asked for a fuller expression set (thinking, surprised, encouraging,
  reacting to daily rewards/new-high-scores) tied into more of the game's
  event surface.
