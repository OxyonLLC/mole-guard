# Core Concepts

Sentinel
Observation device.

Bound Witness
Mutually signed observation between two sentinels.

Origin Chain
Chronological chain of bound witnesses.

BridgeX
Collected and forwarded observations.

Archivist
Stored bound witnesses.

Diviner
Answered questions using archived evidence.

COIN
Incentive layer rewarding participation.

XYO World
Geospatial ownership and staking via Geotokens.

Explore
Originally a network explorer; today focused on XL1.

Mission
Education, research, open development, incentive-driven geospatial network.
