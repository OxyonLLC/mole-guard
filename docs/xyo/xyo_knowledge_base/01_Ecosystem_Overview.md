# Ecosystem Overview

Core mission:
Build an incentive-driven geospatial network where observations become evidence.

Core ideas:
- Sentinels create observations.
- Bound Witnesses are mutually signed observations.
- Bridges relay observations.
- Archivists store them.
- Diviners answer queries.
- Origin Chains create a history of evidence.

Products:
- XY Find It
- XYO Network App
- COIN
- XYO World
- BridgeX
- Explore
- Developer SDKs
