Not registered yet

Add it from Discord with !register <your-wallet> — the same command that saves a wallet for faucet fallback. Registering from the website is not available yet.
What registering does and does not mean

Registering records a standing intent to be included. It is not a promise of an airdrop, an amount, or a date, and no airdrop is scheduled by being on this list. If one happens, this is the record it would be drawn from.
