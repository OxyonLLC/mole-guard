Leaderboards
Games. Quiz. Faucet. Clout. Governance.

Boards rank on different things, so each one says which. The Gaming Hub and Faucet rank by WinLEW actually earned or claimed; Clout ranks by WinLEW contributed to the reserves; Quiz ranks by platform points; Governance ranks by how many proposals someone voted on. Where WinLEW is the measure it is real payout, never raw score, and each board adds a second signal — top level, top score or claim count — so a handful of grinders can't flood everyone else out. Discord and Web are tracked separately wherever both exist.
