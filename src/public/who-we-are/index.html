For wallet providers & security reviewers

If your wallet flagged this site

Wallet security scanners (Phantom's, and others) sometimes flag newer domains as "unverified" by default — that's a domain-age heuristic, not a finding of anything malicious. A few things worth checking directly:

  • The token itself has been live on Solana mainnet since December 2024 — independently checkable via the mint's own on-chain creation history, not just this website's age.
  • Every transaction this site ever asks a wallet to sign is a single, minimal SPL token transfer — the fee payer is always the user's own wallet, and the site never constructs an instruction that creates a token account for a different address (the exact instruction shape used by drainer kits).
  • Every destination address a user can send to from this site is published, address-by-address, at /transparency/ and /burn/ — reviewable before approving anything.
  • This site never requests a seed phrase, private key, or an off-platform payment, in any flow, anywhere.
  • The original bot source is public: github.com/LewSales/Discord-Bot ↗ — the faucet/price/community bot's real code, readable line by line.

If you're reviewing this domain for a wallet's allow-list or safety database, we're reachable at any time via the Discord above to answer questions directly.
