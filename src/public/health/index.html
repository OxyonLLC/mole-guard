What this page is not
Scope
  • It reports whether these routes respond correctly right now, checked from the server over loopback each time you load it. It is not a historical uptime record — there is no stored history behind it, and it does not claim an uptime percentage.
  • A red check means that route was failing at the moment you loaded this page. Reloading re-runs every check from scratch.
  • Data APIs are held to a higher bar than pages: an API must also report success inside its own response body, so a route that returns HTTP 200 while its underlying lookup failed is still counted as unhealthy.
