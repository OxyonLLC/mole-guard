Oxyon Wallet

Verify before you sign.

Live beta · Browser extension + web wallet · formerly GeoWallet

Oxyon Wallet is where identity lives: a non-custodial wallet, as a web app and a browser extension, built on one rule — verify before you sign. Keys never leave the device; nothing is approved blind.

GeoShield

Every request is decoded before it is signed.

  1. InterceptA signing request arrives from any application.
  2. DecodeThe transaction is decoded on-device — no data leaves the wallet.
  3. VerdictA plain-language verdict: what this actually does, and to what.
  4. DecideThe person signs with understanding — or declines with reason.
  5. RecordWhat was approved joins a ledger the owner can audit and act on.

Capabilities

What ships in the foundation.

  • Non-custodial keysStandards-based key derivation with an encrypted on-device vault.
  • Six networksEthereum, Polygon, Optimism, Base, Solana, and XYO Layer One.
  • GeoShield verdictsPure, on-device decoding of transactions and typed data — before signature.
  • Exposure LedgerDiscovers what’s already approved, shows the delta, and prepares the revocation.
  • Proof generationCanonical GeoProof signing payloads — identity that can attest, not just hold.
  • Wallet messagingSend a message to any XL1 address — public, or end-to-end encrypted — with XL1 attached if you like. Experimental.
  • Extension + webA browser extension with a standards-compatible provider, and a full web wallet.

Status

What exists today.

The wallet foundation is released: web wallet, extension, key vault, GeoShield decoding, and the exposure ledger, organized as a set of focused packages. Reputation is scaffolded and waits on the platform’s verification backend; the mobile app is in development. Wallet-to-wallet messaging on XL1 is new and experimental.
