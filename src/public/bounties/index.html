Context

Why this page exists

WinLEW pays real bounties to holders who find and report real bugs — in the Mole Hub, the faucet, or elsewhere across the ecosystem. This page exists so a bounty being owed is just as visible as a bounty being paid — the same "evidence over assumptions" standard as the Burn Center and Transparency Center.

The bounty program itself is always open. A ledger with zero pending rows means everything owed has been paid — not that reporting is closed. If you find a real bug anywhere in the ecosystem, report it on Discord and it can become the next entry here.
Pending means owed, not forgotten. A bounty shown as Pending has been publicly committed to but not yet paid out on-chain. Once it is, this page is updated with the payout transaction — the same day the status changes from Pending to Paid.
Note. One bounty-worthy bug was fixed before anyone had the chance to test or report it, so it does not appear as a ledger row below.
