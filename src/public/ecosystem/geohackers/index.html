GeoHackers
Evidence over assumption.

GeoHackers is a proof-first community platform for Discord servers: instead of trusting a role or a self-reported claim, real community actions — wallet verification, moderation calls, scam reports, vouches — become cryptographically verifiable, shareable proofs anyone can check.

Status
GeoHackers is running on XYO’s XL1 and publishing what it does — proofs written, how many confirmed, and how long they took. The counts are small and deliberately unflattering; they are a record, not a growth chart.
What is it

Reputation you can actually check, not just believe

The core idea: "if something matters, it should be provable." A GeoHackers-verified server turns actions like linking a wallet, claiming a faucet, moderating fairly, or reporting a scam into a signed, on-chain proof — a shareable link anyone can verify, no login required, without ever trusting the person who made the claim.

"Evidence Over Assumption."

How it works

Proofs, not promises

🤝 Co-witnessed proofs

Some actions — like community vouches — need both sides to sign, so no one can fabricate a claim about someone else alone.

🎴 Provably fair games

CryptoSpades, GeoHackers' first game, is built to deal ranked hands from a server-issued seed and replay every move server-side before a score counts. It is not publicly hosted right now. WinLEW's Mole Spades is adapted from it but has no replay verification.

🏅 Rank by proof, not vibes

Members climb a ladder purely from confirmed proof counts, not admin opinion.

GeoHackers & WinLEW

Same builder, and it already shares WinLEW's infrastructure

GeoHackers is a sister project from the same team behind WinLEW — currently hosted alongside WinLEW's own website and services rather than running fully independent infrastructure. That's a hosting detail, not a WinLEW feature: GeoHackers is its own platform, still being finished before it's opened up.

It is an Oxyon community project, run with WinLEW and built by the same team. More about Oxyon at oxyon.io ↗.

CryptoSpades is a GeoHackers project and is not publicly hosted right now; its old Netlify build is retired. Whether it becomes an official $WinLEW game is an open community governance vote — nothing here should be read as a confirmed WinLEW integration yet.
