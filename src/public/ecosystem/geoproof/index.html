GeoProof
A shared language for turning claims into evidence.

GeoProof is a protocol, not an app: it's the shared rulebook that several of these sister projects use to turn a raw observation into a signed, tamper-evident proof — one that a complete stranger can verify without trusting the observer, the checker, or anyone in between.

Status
GeoProof already has a working live demo and a real tool server behind the scenes — it's just not ready to be exposed publicly yet.
What is it

The rulebook underneath the proofs, not a proof itself

Rather than each sister project inventing its own way to sign and verify evidence, GeoProof defines one shared lifecycle every one of them can use: an event gets observed, signed, given a receipt, anchored, and can later be replayed to check nothing was tampered with. It doesn't reimplement any cryptography itself — it defines the shape and the rules, and leans on proven tooling underneath.

Standout details

Built to be checked, not just trusted

🧪 A live tamper test

Its own demo lets you swap in a forged proof and watch verification correctly fail — never a false "verified."

🤖 Works with AI coding tools

Exposes real tools that AI coding assistants can call directly to produce and check tamper-evident audit trails — genuinely required to authenticate first, unlike most tools like it.

📐 Cross-language test vectors

A fixed set of known-good answers so any implementation, in any language, can verify its own math matches the reference.

GeoProof & WinLEW

Foundational, not front-facing

GeoProof isn't something you'd use directly — it's the shared plumbing a few of these other sister projects (like GeoPresence) are built on top of. It comes from the same builder as WinLEW, with no confirmed WinLEW-specific integration today.

It is Oxyon's proof protocol, built by the team behind WinLEW. The specification's status is on oxyon.io ↗.

Nothing on this page is a promise of a launch date. Check back, or watch WinLEW's own announcement channels for when GeoProof actually opens up.
