uBlock
A block producer for the XL1 chain.

uBlock (internally "uProducer") is a command-line toolkit for running an XL1 block producer — staking XYO to your address and earning rewards for producing blocks — plus scanning any XL1 network's chain activity directly.

🖥️ Command-line toolkit 📡 Live chain scanner Coming Soon
Status
uBlock's core CLI tooling already works today, run privately — it's just not ready to be exposed publicly yet.
Not the ad-blocker browser extension you may be thinking of — this uBlock is unrelated infrastructure for the XL1 blockchain.
What is it

Infrastructure, not an app

uBlock is a developer-facing toolkit for XL1 (the XYO Layer One chain): submit transactions, scan the last however-many blocks on any network, and — the main event — run a block producer that stakes XYO and earns real block-production rewards on the network. There's no web interface here; it's a set of command-line tools.

What it's for

A health check and an income stream, in one tool

📊 One-command health check

A single command prints the last several blocks and your wallet balance, no dashboard required.

⛏️ Real block-production rewards

Stake XYO to an address and start producing blocks on the testnet — with mainnet as the eventual target.

🔎 A public transaction explorer

A separate sub-project in the works: a wallet-free, browser-based way to look up any XL1 transaction — currently still being built.

uBlock & WinLEW

Same builder, separate project

uBlock is XYO/XL1-native tooling from the same team behind WinLEW, with no confirmed WinLEW-specific integration today.

It is part of the XL1 infrastructure developed under Oxyon, by the team behind WinLEW. More about Oxyon at oxyon.io ↗.

Nothing on this page is a promise of a launch date. Check back, or watch WinLEW's own announcement channels for when uBlock actually opens up.
