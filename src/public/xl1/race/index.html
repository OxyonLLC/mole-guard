Race board.

Every block on XL1 sequence is a race between producers. This page shows how each producer's candidates reach the pool and which one the finalizer picks, measured from the public candidate pool and the finalized chain.

The rule that decides most blocks

The newest valid candidate wins, not the fastest

The mempool lists pending blocks newest first and the finalizer keeps that order when scores tie. In practice it decides right after the second valid candidate arrives.
