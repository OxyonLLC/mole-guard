1.0.1 is the first full release, the same build that is going to Google Play. It opens on a short welcome: what WinLEW is, its two tokens, and an 18+ confirmation, then the app. It has its own offline screen and a splash. It is signed with the same WinLEW key, so it installs over any earlier beta and keeps your data. Once WinLEW is live on Google Play, updates come from there.

Before you install — read this

Install only the file from this page. Check that the SHA-256 above matches what you downloaded. If anyone sends you a "WinLEW APK" through any other channel — a DM, another site, a forwarded file — do not install it, whoever it appears to be from. Crypto communities are targeted with exactly this trick.

Android will say the app is from an unknown source. That is expected for a beta installed outside the Play Store, and is not a warning about this build specifically.

This is a signed release build — not debuggable, and signed with WinLEW’s own key rather than the shared Android debug key, so a modified copy cannot carry a matching signature. Verifying the checksum is still the way to be certain you have the real one.

Installing

  1. Download the APK on the phone itself.
  2. Open it. Android will warn about installing from an unknown source — allow it for your browser or files app.
  3. Install, then open WinLEW.

Installing over an earlier beta keeps your data. The app never asks for a seed phrase or private key, and it can't move your tokens — it only ever opens winlew.co and your own wallet's official app.

What we need you to try

  1. Connect a wallet from the app’s home screen. It opens Phantom/Solflare to sign, then should return you to WinLEW already signed in.
  2. Then close the app and reopen it. It should come straight back signed in, with one tap to claim — no wallet round trip. That is the whole point; tell us if it asks you to connect again.
  3. If it doesn't return automatically, switch back to WinLEW yourself — it should finish signing you in within a few seconds. Please say which of the two happened.
  4. Check the top and bottom of the screen — nothing should sit under the clock or the gesture bar.
  5. Use the back button around the app and the menu.

Report anything odd in the WinLEW Discord. Screenshots help enormously, and "it did nothing" is a useful report — that's the case we most need to know about.

Known: iOS isn't available yet. If you've already claimed the faucet more than 10 times, verify at winlew.co/verify/ in your normal mobile browser rather than in the app for now.
