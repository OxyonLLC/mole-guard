# Payload B — Enemy Variety & Gameplay Flavor Pass

## Goal
Make Burrow Blaster encounters more memorable by giving enemies clearer roles, stronger wave identity, and more exciting drop targets.

## Included
- Added Charger enemy role with a visible windup and locked dash/lunge behavior.
- Added Carrier enemy role as a high-value target with stronger special-core drops.
- Reworked enemy selection into wave-themed weighted mixes.
- Reworked formation spawns around wave identity: Scout Rush, Armor Push, Splitter Nest, Carrier Raid, Elite Swarm.
- Added Burst Core as a one-time tunnel blast powerup.
- Updated pickup/drop logic so carriers, tanks, chargers, splitters, and bosses feel different to defeat.
- Added visual identities for Charger and Carrier enemies.

## Validation
- JavaScript syntax check: `node --check js/app.js`
- ZIP integrity check: `unzip -t`
