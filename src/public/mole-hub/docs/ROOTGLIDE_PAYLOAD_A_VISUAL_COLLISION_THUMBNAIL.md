# Root Glide Payload A — Visual Identity, Collision Fairness, and Thumbnail Alignment

## Goal
Bring Root Glide closer to the thumbnail/card direction while fixing early readability/collision concerns.

## Built in this pass
- More cinematic cave background with warm amber beacon glow.
- Parallax-style root silhouettes, cave flecks, and border atmosphere.
- More organic obstacle styling for roots, thorns, shale, boots, and shovel hazards.
- Expanded obstacle labels and visual identity so hazards are easier to read.
- Dedicated Root Glide round-rank logic so Root Glide no longer depends on Burrow Blaster scoring helpers.
- Better collision alignment using a Lew body hitbox instead of only a single center point.
- Edge-save scoring when the player barely threads the gap.
- Worm pickup burst, floating score text, and particle feedback.
- Glide trail behind Lew to better match the thumbnail’s motion energy.
- Round-clear arcade banner for Root Glide.
- Reward popup now includes Root Glide rank, worms, edge saves, and rank payout bonus.

## Design target
Root Glide should feel less like a recolored obstacle game and more like Lew flying through a glowing underground tunnel toward a beacon.
