# Pac-Mole Fix Plan

Adapted from the Burrow Blaster process.

## Gameplay issues to correct
- The game was visually too generic compared with the thumbnail.
- The player looked like a tiny dot instead of the thumbnail mole.
- Pickups and enemies lacked identity.
- The game needs to feel like Pac-Man, but with WinLEW changes.

## Patch direction
- Make the player match the Pac-Mole thumbnail character.
- Upgrade the maze into glowing blue underground tunnel blocks.
- Keep Pac-Man-style collection/chase pressure.
- Use golden worms as the main level-clear pickups.
- Use glow-grubs as power-mode pickups.
- Use beetle raiders as enemies.
- Keep Burrow Dash as the signature WinLEW twist.
- Preserve reward box progression and 20-level campaign flow.

## Current status
Payload B applies the visual identity correction and keeps Payload A's render/start hotfix.
