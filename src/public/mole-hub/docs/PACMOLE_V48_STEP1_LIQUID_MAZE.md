# Pac-Mole v48 Step 1 — Liquid Maze Foundation

This repair pass focuses only on Pac-Mole's maze foundation.

## Fixed / improved
- Larger 32x18 maze layout with a slightly larger tile scale.
- More golden worm/globe coverage across valid paths.
- Less dead-feeling empty path space.
- Fewer long thick walls; wall segments are shorter with more breaks.
- A visible central beetle den is added to the middle of the map.
- Beetles now spawn/respawn from the central den instead of the tile where they died.
- Level copy updated to describe the rebuild.

## Not changed yet
- Reward math is unchanged.
- Burrow traversal remains non-destructive.
- This is a foundation pass before more advanced enemy AI / liquid movement polish.
