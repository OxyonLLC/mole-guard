# Payload B Patch Notes

## Enemy Roles
- Raider remains the baseline enemy.
- Scout Raider remains the fast pressure enemy.
- Tank Burrower remains the high-HP space-control enemy.
- Splitter Bug continues to split into mini enemies.
- New Charger enemy telegraphs before lunging toward the player.
- New Carrier enemy carries reward cargo and has improved drop behavior.

## Wave Identity
- Wave 1: Raider Warmup
- Wave 2: Scout Rush
- Wave 3: Armor Push
- Wave 4: Splitter Nest
- Wave 5: Carrier Raid
- Wave 6: Elite Swarm / Guardian Chamber

## Drop System
- Carriers have a very high chance to drop a special core.
- Tanks and bosses keep strong drop chances.
- Chargers can drop Burst or Laser-style rewards.
- Burst Core was added as a one-time blast that clears nearby threats.

## Regression Notes
- Existing reward overlay flow was preserved.
- Start/resume/restart behavior was not intentionally changed.
- Root Glide, Pac-Mole, and DigLEW were not intentionally modified.
