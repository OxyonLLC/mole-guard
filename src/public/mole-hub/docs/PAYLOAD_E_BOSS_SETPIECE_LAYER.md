# Payload E — Boss / Setpiece Layer

## Goal
Make Burrow Blaster's boss layer feel like a real setpiece instead of a larger enemy with more HP.

## Built Systems
- Boss profile rotation:
  - Shardjaw Beetle
  - Ironback Burrow King
  - The Drill Eater
- Boss intro presentation with variant-specific title/subtitle/colors.
- Boss phase logic:
  - Phase 1: standard pressure
  - Phase 2: armor cracked / changed pattern
  - Phase 3: rage tunnel / faster pressure
- Boss-specific attack behavior:
  - Shardjaw favors rock pressure and charger/raider support.
  - Ironback favors side roots, armor pressure, and tank support.
  - Drill Eater favors beam pressure and scout support.
- Boss defeat presentation:
  - defeat banner
  - BOSS BROKEN floating text
  - stronger shake/flash feedback
  - boss stash unlock message
- Boss reward logic:
  - guaranteed boss stash shards
  - guaranteed premium core drop aligned with boss type

## Lockup Notes
This closes the planned Payload A–E roadmap cycle and gives the project a clean checkpoint for future tuning, QA, and content expansion.
