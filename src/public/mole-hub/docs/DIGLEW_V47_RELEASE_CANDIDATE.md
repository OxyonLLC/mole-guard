# DigLEW v47 Release Candidate

This RC locks the current working DigLEW direction after Step 6.

## Locked gameplay
- 3-road runner: Risk Road, Main Road, Safe Road.
- Up/down changes roads.
- Space / Shift / X dashes through cracked rocks.
- No jump / duck mechanics.
- Top road has richer rewards and higher risk.
- Bottom road is safer, but lower value and not free to camp.
- Blue dash charges, hearts, coins, worms, and gems support the run.
- Checkpoints open reward boxes.
