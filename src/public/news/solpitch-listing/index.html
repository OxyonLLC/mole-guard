We Built It First. Now We're Showing People.

$WinLEW is listed on SolPitch — a directory where the community votes. A listing is exposure, not a seal of approval, and the difference matters.

$WinLEW is now listed on SolPitch, a Solana project directory where visitors discover projects and vote on them.

Verified rather than announced: the listing was checked on August 18, 2026 with a real browser, because SolPitch is a single-page app whose raw HTML contains no project content — an HTTP 200 on that URL would prove nothing at all. The render returned the live page: Lets EveryOne Win $WinLEW, tagged Memecoin, carrying a Featured badge, with 6 votes at the moment it was checked.

That number is dated on purpose. It is a live counter and it will be wrong by the time you read this — which is exactly why it carries a timestamp instead of being quoted as a fact about the present.

What a listing is, and what it is not

Being listed somewhere is visibility. It is not verification, it is not an endorsement, and it is not a judgement by anyone that this project is good. A directory listing means a form was filled in and accepted.

This is worth saying plainly because plenty of projects present a listing as though it were a credential. It is not one, and a site that argues for checkable claims should be the first to say so about its own good news.

What it does do is put the work in front of people who have never seen it. That is the entire point.

Why this is late, and deliberately so

The order matters here. This project spent a long time building before asking for attention — a faucet, games, quizzes, Proof of Value, wallet verification, governance, burns, liquidity, security work, Discord bots, a transparency centre.

None of that is a claim you have to take on faith. Every one of those has a page on this site with the receipts attached: the burn ledger with a transaction for every burn, the transparency centre with the wallets named, the giveaway records showing 12,228,500 $WinLEW given away across 30 transfers — including the eighteen we cannot explain, listed anyway.

A landing page was not called an ecosystem. The thing was built, and it is checkable, and that is why showing it to people now is not the same as asking them to believe a pitch.

You can actually participate in this one

SolPitch is voted on by whoever turns up. So this one is genuinely open: find the listing, read it, and vote if you think it deserves it.

Read it first. If a directory listing convinces you of anything on its own, the problem is the directory.

Proof of Value — not Proof of Wealth.
