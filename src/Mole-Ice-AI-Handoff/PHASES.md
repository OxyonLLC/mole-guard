# Mole Ice build phases

## Phase 1 — Prove the fun (current)

- Playable 15×13 frozen mine
- Desktop and touch controls
- Push, slide, stop, shatter, and crush mechanics
- Chasing Glitch Bug enemy
- Combo scoring, lives, rounds, pause, and simple sound
- Responsive arcade presentation

Success gate: moving and crushing enemies feels good before adding economy or accounts.

## Phase 2 — Build the game

- Three enemy personalities: Chaser, Breaker, Sneak
- Data-driven handcrafted levels and difficulty curve
- Proof Blocks and the temporary Proof of Value state
- Chain reactions, clearer combo tiers, power-ups, and boss rounds
- Animation, particles, music, accessibility settings, and game balancing

## Phase 3 — Make it WinLEW-ready

- Signed server-created sessions and nonces
- Compact event stream for moves, pushes, kills, and round completion
- Server replay/sanity validation and suspicious-run flags
- Existing account/wallet integration and verified leaderboards
- No token payout yet

## Phase 4 — Controlled rewards

- Separate arcade score from verified reward score
- Daily limits, payout-cycle integration, and duplicate-session protection
- Small closed beta, telemetry review, exploit testing, and tuning
- Governance-approved WinLEW reward rules before activation

## Phase 5 — Release

- 20-round campaign, achievements, seasonal boards, and live balancing
- Mobile/browser compatibility pass
- Security review, load testing, public launch, and measured reward rollout
